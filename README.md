# Thinking in Public

A reading surface for the live RSS feed at https://dergigi.com/thoughts.xml. Writing stays on dergigi.com. A new post tagged `thoughts` can appear here without rebuilding this site.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints. The page fetches the live feed in the browser.

## Write elsewhere

dergigi.com is the only writing workflow. Do not add posts in this repo.
